# Iqbal Nawaz - Flutter Developer Portfolio

A modern and responsive developer portfolio built with Flutter and Dart.

This portfolio showcases my skills, projects, education, and contact information as a Computer Science student and Flutter Developer.

---

##  About The Project

This project is a personal portfolio application designed to present my development journey and Flutter projects in a clean, modern, and responsive interface.

The portfolio is built using Flutter and follows a component-based structure where each section is separated into its own widget file.

---

##  Features

- Responsive design for mobile, tablet, and desktop
- Modern dark developer-themed UI
- Hero section with profile image
- About Me section
- Skills section with technology cards
- Projects showcase
- Education section
- Contact section
- GitHub profile integration
- Email contact integration
- Responsive navigation
- Mobile navigation drawer
- Smooth section scrolling
- Project image previews
- Hover effects on desktop
- Material 3 design
